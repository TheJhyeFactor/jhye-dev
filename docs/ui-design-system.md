# UI design system

A personal engineering portfolio with editorial typography, readable evidence and a visible career path.

- Background `#f6f5f0`; text `#17231f`; muted `#5e6862`; accent `#245e47`; dark section `#172e25`.
- System sans-serif body/display, Georgia italic emphasis, restrained monospace metadata.
- Content width up to 1240px; stacked mobile layouts under 760px; intermediate layout under 1050px.
- Separate images and copy. Real application screenshots, accurate photo captions and complete case-study routes.
- Semantic landmarks, one page h1, visible focus, minimum navigation targets, reduced-motion support.
- Essential work and career chapters use normal document scrolling, not carousels or modal-only content.
- Dates, categories and lifecycle labels support the story rather than replacing it.
- Departure drafts are visibly marked and excluded from the printable résumé.
