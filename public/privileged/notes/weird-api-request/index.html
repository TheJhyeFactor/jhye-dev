Why This API Request Was Doing Something Weird

Two requests that looked identical, one tiny header difference, and a useful debugging habit.

Written by Jhye
#api#debugging#web
Demo write-up

This is fictional sample content for the notebook. It describes a lab scenario, not a real finding or a project Jhye has released.

On this page
Look at the whole requestChange one thing

In this fictional debugging example, a local endpoint accepts a JSON request from one client but rejects the same-looking request from another. Comparing just the bodies hides the difference.

Look at the whole request

The first client sets Content-Type: application/json. The second client sends a JSON-looking body with a different media type. The server’s body parser uses that header to decide how to interpret the bytes.

Change one thing

Keep the URL, method, body, and authentication context fixed. Change only the content type and compare the result. A controlled comparison turns a vague “curl works but the app doesn’t” into something testable.

My useful habit from this lab: write down the entire request, with secrets redacted, before assuming the server is being inconsistent.
