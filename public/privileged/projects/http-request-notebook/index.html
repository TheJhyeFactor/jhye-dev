A small, useful constraint

Store an experiment as a baseline request, one deliberate change, and a short observation. Keep secrets out of saved requests and use synthetic data when sharing results.

A record you can trust

The value is in traceability: knowing what was sent, what came back, and what inference the result supports. An export should retain that distinction rather than flattening every note into a finding.

A useful tool can be small. A repeatable experiment and a clear explanation are a reasonable place to start.
