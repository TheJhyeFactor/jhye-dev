This is a demo project entry, showing how a small tool could be documented in Privileged. It is not a claim that Jhye has released this project.

The idea

Check whether a few expected local development services are accepting TCP connections, without turning a quick debugging tool into a network scanning platform.

The scope is explicit: 127.0.0.1, three fixed ports, one short timeout per connection attempt.

The core

A successful connection only establishes that a TCP connection was accepted. It does not identify the application or prove it is working correctly.

What I’d add next

If this became a real tool, the next useful feature would be structured output for another script to consume. Parallel execution, host discovery, and a dashboard are unnecessary for the initial question.

The corresponding sample note explains the same experiment in a shorter format.
